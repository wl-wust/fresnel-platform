# 测量会话与多帧图像使用说明

## 手机端

1. 在“拍照”页选择测量方法，点击“新建会话”。
2. 在“图像角色”中选择当前要采集的组：
   - 钠光条纹
   - 激光参考条纹
   - 无透镜条纹
   - 加透镜条纹
   - 标定图
3. 拍照或从相册选择图片。每张图片会追加到当前角色，不会覆盖旧图。
4. 平台自动提取 Δx，并显示当前角色的帧数、均值与标准差。
5. 导出 `record.json` 时，导出的是 `bp.record/2` 会话数据。

## PC 端

1. “波长计算”页可直接使用：
   - 基本公式法
   - 比值法
   - 光线追迹法
   - 横向放大率法
   - N-BK7 等效棱镜角 A_eff
2. 图像分析页顶部显示当前会话的角色完成度。
3. 选择图像角色后再分析图片，识别结果会写入该角色。
4. 手机导出的 `bp.record/2` 可在“历史记录”页导入。

## 追迹法

默认追迹值为 MATLAB 严格追迹：

```text
d_trace = 0.90213 mm
```

只适用于：

```text
a = 50 mm
A = 1.0°
n = 1.5168
t ≈ 0.17 mm
λ = 589.3 nm
```

改变这些参数后，必须重新运行 MATLAB 追迹，不能继续使用内置值。

## N-BK7 等效棱镜角

输入棱镜位移 `Δx` 和干涉区宽度变化 `Δw`，平台使用：

```text
tan β = -2Δx/Δw
A_eff = |β| / (n_N-BK7(λ) - 1)
```

`A_eff` 是由偏折角反演的等效棱镜角，不是分光计直接测角。
