# 菲涅耳双棱镜机械装置外观模型设计

## 目标

在现有 `comsol/FresnelBiprism_RayOptics.mph` 中增加一版教学示意级的机械装置外观，让用户可以在同一个 COMSOL 文件里查看完整实验台和原有射线光路。

外观模型只用于显示，不参与材料赋值、网格划分、Ray Optics 求解或数值验证。

## 非目标

- 不建模真实的调节机构公差、螺纹、螺钉连接强度或零件装配关系。
- 不修改现有玻璃双棱镜的尺寸、位置、折射率和射线追踪参数。
- 不把机械外观件并入现有光学几何序列。
- 不替代 MATLAB/网页平台的条纹强度分析。

## 实现结构

在同一个 COMSOL 组件中新增独立的几何序列 `mech`，与已有光学几何 `geom1` 分开：

- `geom1`：原有 3D 薄片双棱镜，继续供 Geometrical Optics 使用。
- `mech`：机械外观几何，仅用于显示。

外观件全部使用毫米单位，并与光学模型共享以下位置：

- 点光源/狭缝：`x = -50 mm`，中心 `y = 0`。
- 双棱镜中心：`x = 0 mm`。
- 光屏：`x = 1000 mm`。
- 导轨长度覆盖 `x = -80 ... 1080 mm`。

## 外观组件

1. 光学导轨：长条形灰色底座，带两条纵向凸轨。
2. 前后支脚：两个深灰色矩形支脚，给导轨提供落地感。
3. 三个滑块：分别位于光源、双棱镜和光屏位置，带简化锁紧旋钮。
4. 光源组件：圆形灯壳、短圆柱镜筒、竖直狭缝片和一支支撑立柱。
5. 双棱镜支架：V 形夹持座、两根立柱和底部滑块，玻璃双棱镜保持原光学尺寸。
6. 光屏组件：白色矩形屏面、深色边框、中心立柱和底部滑块。

## 视觉约定

- 导轨和支脚：深灰/中性灰。
- 滑块和立柱：蓝灰金属色。
- 光源壳体：暖橙色。
- 玻璃双棱镜：浅青色透明。
- 光屏：白色屏面配深色边框。
- 机械件使用独立颜色，便于与 `gop.L` 着色的射线区分。

## 交互与查看

- 在模型树中可分别显示 `geom1` 和 `mech`。
- 光学结果继续通过 `Fresnel Biprism Ray Trajectories` 查看。
- 完整外观截图会另外导出为 `FresnelBiprism_Apparatus_Appearance.png`。
- 原有 `FresnelBiprism_OpticalPath_Interference.png` 保持不变。

## 验证

- 重新加载 `.mph` 后，原有 `Ray Tracing Study`、`解 1` 和轨迹绘图仍存在。
- `mech` 几何能独立构建，且不产生材料和物理场选择。
- 光学求解结果不因新增外观几何而重新计算或改变。
- 新增外观模型中，三个关键组件的位置与 `x=-50/0/1000 mm` 一致。
- 导出外观截图，确认导轨、光源、棱镜架和光屏均可见且不遮挡射线主视图。

## 风险

- 本机 COMSOL GUI 可能锁定正在打开的 `.mph` 文件；实现时先关闭当前模型窗口或在新文件名上生成，再替换最终文件。
- 外观件数量较多，若全部放在一个工作平面内可能降低几何树可读性；将使用命名清晰的子特征和独立几何序列。
