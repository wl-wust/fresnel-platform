# Fresnel Double Prism Interference Experiment AI Platform

## 部署状态

- **PC 版**: https://wl-wust.github.io/fresnel-platform/
- **手机版**: https://wl-wust.github.io/fresnel-platform/mobile.html
- **光学模拟**: https://wl-wust.github.io/fresnel-platform/optical.html

## 功能特性

- 条纹图像分析（纯前端 FFT+峰值检测）
- 波长计算（基本公式法、比值法）
- 最小二乘数据拟合
- 不确定度评定
- 多路径加权合成
- 历史记录管理（localStorage）
- 光学导轨模拟（2D Canvas）
- 手机/PC UI 切换

## 技术栈

- 纯前端实现，无需后端服务器
- Chart.js 数据可视化
- localStorage 数据持久化
- GitHub Pages 静态托管

## 访问方式

电脑访问：直接输入网址
手机访问：同样输入网址，支持流量访问
